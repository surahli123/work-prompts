# Work prompts

Prompts and instructions for the coding agent on the work laptop. The laptop reads this repository and writes nothing back. The code is in a separate repository: [kangaroo](https://github.com/surahli123/kangaroo), the search experiment agent.

| File | What it is | Status |
|---|---|---|
| [01-materials-prompt.md](01-materials-prompt.md) | Questions about the current work agent. The answers gave the materials for the kangaroo design | Done |
| [PORTING.md](PORTING.md) | How the work agent becomes kangaroo: the phase order, the aliases, the four seams, the test rules, what to send home | Current. A copy of the kangaroo file |
| [02-phase0-audit-prompt.md](02-phase0-audit-prompt.md) | Phase 0: a read-only audit of the work repository. It writes `PLAN.md` | Next |

Do one phase of `PORTING.md` in each session. Approve each plan before the agent edits. Only counts come home: no metric values, no rows and no names from the alias map.
